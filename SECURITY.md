# Security Policy

## Supported Versions

Security fixes are provided for supported versions of FrameCast as determined by the project maintainer.

| Version | Supported |
|---|---|
| Latest stable release | Yes |
| Latest pre-release | Best effort |
| Older releases | No guarantee |
| Unmaintained versions | No |

Users are encouraged to use the latest available release to receive applicable security fixes and improvements.

Support for a particular version may change over time. Publishing a newer release does not guarantee that every older version will receive a security update.

## Reporting a Vulnerability

If you discover a potential security vulnerability in FrameCast, please report it responsibly.

**Do not disclose unpatched vulnerabilities publicly before giving the maintainer a reasonable opportunity to investigate.**

### How to Report

Use GitHub's **Private vulnerability reporting** feature if it is enabled for the FrameCast repository.

If private vulnerability reporting is unavailable, contact the maintainer through an official contact method listed in the repository.

Do not submit undisclosed security vulnerabilities through public GitHub issues.

### What to Include

Please provide as much relevant information as possible:

- A description of the vulnerability.
- The affected FrameCast version or versions.
- The Minecraft version and mod loader version.
- Your operating system, if relevant.
- Clear steps to reproduce the issue.
- The potential impact.
- Relevant logs, screenshots, or proof-of-concept files.
- Any known workarounds.

Do not include passwords, access tokens, private keys, or unrelated personal information.

## Response and Remediation

The maintainer will review reports and make reasonable efforts to assess their validity, severity, and impact.

Depending on the findings, the maintainer may request additional information, investigate affected versions, develop a fix, publish a security update, or determine that the report does not describe a vulnerability.

Response and resolution times depend on the severity and complexity of the issue and the resources available. No specific response or resolution time is guaranteed.

## Responsible Disclosure

Reporters are requested to allow reasonable time for investigation and remediation before publicly disclosing technical details that could put users at risk.

When appropriate, the project may publish a security advisory describing the affected versions, potential impact, available fixes, and recommended actions.

Security researchers may be credited for valid reports with their consent.

## Scope

This policy applies to security vulnerabilities in FrameCast's source code, official releases, and project-controlled distribution mechanisms.

Issues originating exclusively in third-party software, unofficial forks, modified builds, or external services may be outside the project's direct control. Reports involving these components may still be considered when they affect FrameCast.

## Security Updates

When a security issue is confirmed and a fix is available, users should update to a release that includes the fix as soon as reasonably possible.

If no fix is available, users should follow any mitigation guidance published by the project.

Security updates may require users to install a newer version of FrameCast or one of its dependencies.

## No Guarantee

Submitting a security report does not guarantee a particular response time, a security advisory, public credit, or compensation.

FrameCast is provided subject to the terms of its applicable license and warranty disclaimer.

## Policy Changes

This policy may be updated as FrameCast and its maintenance practices evolve. The current version published in the official repository is authoritative.
